# Agent Configuration (Template)

## Environment variables
- `SWAIF_ORCHESTRATOR_URL` (required)
- `SWAIF_AGENT_NAME` (recommended)
- `SWAIF_WORKSPACE_ROOT` (recommended)
- `SWAIF_ALLOWLIST_COMMANDS_FILE` (recommended)
- `SWAIF_ALLOWLIST_PATHS_FILE` (recommended)

## Defaults (template)
- Use localhost defaults for MVP, but document production overrides.
